## Building release binaries

The host is NixOS, so native release builds point at a `/nix/store` dynamic loader and fail on
other distributions. Build both binaries in the Ubuntu 22.04 image from the `Dockerfile`, giving
glibc 2.35+:

- AppImage: `podman_build`. Its `podman run -it` needs a TTY; without one, run
  `podman run --rm --device /dev/fuse --cap-add SYS_ADMIN -v "$PWD:/hd_fpv_video_tool:Z"
  hd_fpv_video_tool_build`. The output is `hd_fpv_video_tool.AppImage` in the repository root,
  uploaded as `hd_fpv_video_tool_x86_64_v<version>.AppImage`.
- Font tool: in `../hd_fpv_osd_font_tool`, run `podman run --rm -v "$PWD:/src:Z" -w /src
  -e CARGO_TARGET_DIR=/src/target/ubuntu2204 --entrypoint cargo hd_fpv_video_tool_build build
  --release --locked`. Strip the binary, compress it with `xz -9` and upload it as
  `hd_fpv_osd_font_tool-linux64-v<version>.xz`.

The binaries were only checked with `--version`.
