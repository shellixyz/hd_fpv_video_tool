# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the status
strings used in this repository's local issue tracker.

| Label in skills | Status in this tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

`done` is an additional local workflow status for completed work; it is not a canonical triage
role.
